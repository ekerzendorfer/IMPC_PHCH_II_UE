Quick reference

🧠 Five starting formulas

Useful starting equations for the exercises. Unit 01 practises choosing compatible units.

$$\rho = \frac{m}{V}$$
$$n = \frac{m}{M}$$
$$c = \frac{n}{V}$$
$$p V = n R T$$
$$x_i = \frac{n_i}{n_{\text{tot}}}$$
